# Спецификация Системы Команд (ISA)
## 1. Архитектурные особенности
* **Архитектура:** Фон Неймана 
* **Тип системы команд:** CISC 
* **Управление:** Hardwired 
* **Ввод-Вывод:** Memory-Mapped I/O 
* **Строки:** Pascal-strings 

## 2. Регистровый файл
*   **R0-R7:** Регистры общего назначения (32 бита)
*   **PC:** Счетчик команд
*   **EPC:** Регистр для сохранения адреса прерванной команды при возникновении прерывания
*   **IR:** Регистр текущей инструкции
*   **Flags:** Флаги состояния АЛУ (Z - ноль, N - отрицательный, C - перенос, V - переполнение)
*   **IE:** Флаг прерываний

## 3. Набор Инструкций

### Арифметические и логические операции 
Для `ADD` и `SUB` поддерживаются все режимы адресации - регистр, константа, память. Для остальных операций - режимы - регистр, константа

| Мнемоника | Синтаксис | Описание |
| :--- | :--- | :--- |
| **ADD** | `ADD R_d, Op1, Op2` | `R_d = Op1 + Op2` |
| **SUB** | `SUB R_d, Op1, Op2` | `R_d = Op1 - Op2` |
| **MUL** | `MUL R_d, R_s, Op2` | `R_d = R_s * Op2` (Op2 - регистр или константа) |
| **DIV** | `DIV R_d, R_s, Op2` | Целочисленное деление `R_d = R_s / Op2` |
| **MOD** | `MOD R_d, R_s, Op2` | Остаток от деления `R_d = R_s % Op2` |
| **AND** | `AND R_d, R_s, Op2` | Побитовое И |
| **OR**  | `OR  R_d, R_s, Op2` | Побитовое ИЛИ |
| **LSL** | `LSL R_d, R_s, #imm` | Логический сдвиг влево на константу |
| **LSR** | `LSR R_d, R_s, #imm` | Логический сдвиг вправо на константу |

*Где `Op` может быть:*
*   `R_x` — регистр (R0-R7)
*   `#imm` — непосредственное значение (константа)
*   `[addr]` или `[R_x]` — значение из памяти по адресу (только для ADD/SUB)

### Работа с памятью и строками
Используются сложные режимы адресации для эффективной работы с массивами и Pascal-строками

| Мнемоника | Синтаксис | Описание |
| :--- | :--- | :--- |
| **LOAD** | `LOAD R_d, [addr]` | Загрузить 32-битное слово из памяти в регистр |
| **LOAD** | `LOAD R_d, [R_b + R_i]` | Загрузить слово по адресу `R_b + R_i` (База + Индекс) |
| **STORE** | `STORE [addr], R_s` | Сохранить 32-битное слово из регистра в память |
| **LOAD_BYTE** | `LOAD_BYTE R_d, [R_b + R_i]` | Загрузить 1 байт из памяти (для чтения символов `pstr`) |
| **STORE_BYTE**| `STORE_BYTE [R_b + R_i], R_s`| Сохранить 1 байт в память (для записи символов `pstr`) |

### Ветвление и циклы

| Мнемоника | Синтаксис | Описание |
| :--- | :--- | :--- |
| **CMP** | `CMP Op1, Op2` | Сравнить операнды, установить флаги (Z, N, V) |
| **JMP** | `JMP addr` | Безусловный переход на адрес `addr` |
| **JEQ** | `JEQ addr` | Переход, если равно (Z = 1) |
| **JNE** | `JNE addr` | Переход, если не равно (Z = 0) |
| **JLT** | `JLT addr` | Переход, если меньше (N != V) |
| **JGT** | `JGT addr` | Переход, если больше |

### Системные команды и прерывания 

| Мнемоника | Синтаксис | Описание |
| :--- | :--- | :--- |
| **INT_ENABLE** | `INT_ENABLE` | Разрешить обработку прерываний (IE = 1) |
| **INT_DISABLE** | `INT_DISABLE` | Запретить обработку прерываний (IE = 0) |
| **RETI** | `RETI` | Возврат из прерывания (восстанавливает PC из EPC, включает прерывания) |
| **HALT** | `HALT` | Остановка процессора |

## 4. Организация Ввода-Вывода (Memory-Mapped I/O)
В соответствии с тегом `mem`, порты ввода-вывода не имеют отдельных инструкций, а отображаются в память. Транслятор и процессор используют зарезервированные адреса:
*   **`0x80`** — Порт ввода (Input Port)
*   **`0x84`** — Порт вывода (Output Port)

Пример:Команда `LOAD R1, [0x80]` считывает входной символ. Команда `STORE [0x84], R1` выводит символ

## 5. Обработка Прерываний
1. При возникновении внешнего прерывания (сигнал от симулятора) и если `IE = 1`:
2. Процессор сохраняет текущий `PC` в регистр `EPC`.
3. Устанавливает `IE = 0` (запрещает вложенные прерывания).
4. Загружает в `PC` адрес вектора прерывания (например, `0x0000`).
5. Выполняется обработчик прерывания, написанный на моём языке.
6. Обработчик завершается командой `RETI`, которая восстанавливает `PC` из `EPC` и возвращает `IE = 1`.

### 6. Карта памяти
Для предотвращения конфликтов между кодом и данными, память логически разделена на фиксированные зоны:

| Диапазон адресов | Назначение | Описание |
| :--- | :--- | :--- |
| **`0x0000` – `0x00FF`** | **Обработчик прерываний** | Сюда транслятор размещает код из блока `interrupt { ... }`. Точка входа при прерывании — `0x0000`. |
| **`0x0100` – `0x1FFF`** | **Код основной программы** | Сюда транслируются инструкции основной программы. Начало выполнения: `0x0100`. |
| **`0x2000` – `0x2FFF`** | **Статические данные** | Строковые литералы (Pascal-строки) и крупные числовые константы, не помещающиеся в непосредственную адресацию. |
| **`0x3000` – `0x3FFF`** | **Глобальные переменные** | Область для переменных, объявленных через `let`. Выравнивание: 4 байта для слов, 1 байт для символов. |
| **`0x4000` – `0x5FFF`** | **Буфер ввода (`trap`)** | Область, куда обработчик прерываний посимвольно сохраняет входящие данные. |
| **`0x6000` – `0x6FFF`** | **Временные буферы** | Используется алгоритмами для промежуточных вычислений (например, инверсия цифр при преобразовании числа в строку). |
| **`0x0080`** | **Порт ввода (MMIO)** | Специальный адрес. Чтение (`LOAD`) инициирует запрос токена у модели. |
| **`0x0084`** | **Порт вывода (MMIO)** | Специальный адрес. Запись (`STORE`) отправляет токен в буфер вывода модели. |
