# Спецификация машинного кода

## 1. Общие параметры

- **Размер машинного слова:** 32 бита (4 байта)
- **Порядок байт:** Little-endian 
- **Адресация:** Байтовая
- **Длина инструкций:** Переменная (от 1 до 5 байт)

## 2. Кодирование опкода

- **Размер поля опкода:** 8 бит (1 байт)
- **Порядок байт в многобайтовых командах:** Little-endian

## 3. Поля регистров

- **Количество регистров общего назначения:** 8 (R0–R7)
- **Размер поля номера регистра:** 4 бита 
- **Кодирование номеров регистров:**
  - `0000` – `0111` (0–7): R0–R7 (обычные регистры)
  - `1000` – `1110` (8–14): зарезервировано
  - `1111` (15): R_INT (специальный регистр прерываний, read-only)
- **R_INT:** Кодируется как регистр с номером 15. Чтение разрешено, запись запрещена (аппаратно).

## 4. Структура инструкции (единый скелет)

Все инструкции имеют общее начало из 3 байт (если нужны регистры):

```
[ Байт 0: ОПКОД (8 бит) ]
[ Байт 1: Rd (4 бита) | Rs (4 бита) ]
[ Байт 2: MODE (4 бита) | Rt (4 бита) ]
[ Груз: 0, 1 или 2 байта в зависимости от MODE ]
```

Для команд без операндов (`halt`, `reti`, `int_enable`, `int_disable`) — только байт.

## 5. Режимы адресации (MODE)

| MODE (двоичный) | MODE (hex) | Что значит второй операнд | Длина груза | Общая длина команды |
|---|---|---|---|---|
| `0000` | 0x0 | Регистр (Rt) | 0 байт | 3 байта |
| `0001` | 0x1 | Константа 8 бит (знаковая) | 1 байт | 4 байта |
| `0010` | 0x2 | Константа 16 бит (знаковая) | 2 байта | 5 байт |
| `0011` | 0x3 | Прямой адрес `[addr16]` | 2 байта | 5 байт |
| `0100` | 0x4 | Косвенный `[Rs]` | 0 байт | 3 байта |
| `0101` | 0x5 | База+индекс `[Rs + Rt]` | 0 байт | 3 байта |
| `0110` | 0x6 | Константа+индекс `[addr16 + Rt]` | 2 байта | 5 байт |
| `0111` – `1111` | — | Зарезервировано | — | — |

| Мнемоника | Опкод (hex) | Допустимые MODE | Описание |

| `sub` | 0x01 | 0, 1, 2, 3, 4, 5, 6 | Вычитание |

| `or` | 0x07 | 0, 1 | Побитовое ИЛИ |
| `lsl` | 0x08 | 1 | Логический сдвиг влево (только константа) |
| `lsr` | 0x09 | 1 | Логический сдвиг вправо (только константа) |

## 7. Специальные случаи кодирования

### Команды без операндов (1 байт)
`halt`, `reti`, `int_enable`, `int_disable` — только опкод.

### Команды перехода (3 байта)
`jmp`, `jeq`, `jne`, `jlt`, `jgt` — опкод + 16-битный адрес (little-endian).

### Команды `lsl`, `lsr` (4 байта)
Только константа (MODE=1): опкод + Rd|Rs + MODE|неиспользуемый + imm8.

### Команды `adc` (3 или 4 байта)
Работает как `add`, но добавляет флаг переноса C: `Rd = Rs + Op2 + C`.
Используется для 64-битной арифметики.

## 8. Примеры кодирования

### Пример 1: `halt`
- Опкод: 0x43
- Машинный код: `43` (1 байт)

### Пример 2: `add r0, r1, r2`
- Опкод: 0x00
- Байт 1: Rd=0, Rs=1 → `0x01`
- Байт 2: MODE=0 (регистр), Rt=2 → `0x02`
- Машинный код: `00 01 02` (3 байта)

### Пример 3: `add r0, r0, #5`
- Опкод: 0x00
- Байт 1: Rd=0, Rs=0 → `0x00`
- Байт 2: MODE=1 (константа 8 бит), Rt=не используется → `0x10`
- Груз: `05` (1 байт)
- Машинный код: `00 00 10 05` (4 байта)

### Пример 4: `load r0, [0x3000]`
- Опкод: 0x10
- Байт 1: Rd=0, Rs=не используется → `0x00`
- Байт 2: MODE=3 (прямой адрес), Rt=не используется → `0x30`
- Груз: `00 30` (2 байта, little-endian: 0x3000 → 00 30)
- Машинный код: `10 00 30 00 30` (5 байт)

### Пример 5: `store_byte [0x4000 + r1], r0`
- Опкод: 0x13
- Байт 1: Rd=0 (что сохраняем), Rs=не используется → `0x00`
- Байт 2: MODE=6 (константа+индекс), Rt=1 (индекс) → `0x61`
- Груз: `00 40` (2 байта, little-endian: 0x4000 → 00 40)
- Машинный код: `13 00 61 00 40` (5 байт)

### Пример 6: `load r0, R_INT`
- Опкод: 0x10
- Байт 1: Rd=0, Rs=не используется → `0x00`
- Байт 2: MODE=0 (регистр), Rt=15 (R_INT) → `0x0F`
- Машинный код: `10 00 0F` (3 байта)

### Пример 7: `adc r5, r1, r3` (64-битное сложение старших частей)
- Опкод: 0x02
- Байт 1: Rd=5, Rs=1 → `0x51`
- Байт 2: MODE=0 (регистр), Rt=3 → `0x03`
- Машинный код: `02 51 03` (3 байта)

### Пример 8: `jmp while_0` (где while_0 = 0x0150)
- Опкод: 0x30
- Груз: `50 01` (2 байта, little-endian: 0x0150 → 50 01)
- Машинный код: `30 50 01` (3 байта)

## 9. Переменная длина команд 

| Команда                      | Длина   |
| ---------------------------- | ------- |
| `halt`                       | 1 байт  |
| `add r0, r1, r2`             | 3 байта |
| `add r0, r0, #5`             | 4 байта |
| `load r0, [0x3000]`          | 5 байт  |
| `store_byte [0x4000+r1], r0` | 5 байт  |
| `jmp label`                  | 3 байта |

## 10. 64-битная арифметика

Для работы с 64-битными числами используется пара регистров `(R_even, R_odd)`:
- Младшие 32 бита — в чётном регистре
- Старшие 32 бита — в нечётном регистре

Пример сложения двух 64-битных чисел:
```assembly
; Число A: (R1, R0), Число B: (R3, R2), Результат: (R5, R4)
add r4, r0, r2    ; Сложить младшие части
adc r5, r1, r3    ; Сложить старшие части с переносом
```

## 11. Флаги состояния

Флаги (Z, N, C, V) — это 4 бита в специальном регистре `Flags`, который **не имеет номера** и недоступен программисту напрямую.

- Устанавливаются командами `cmp`, `add`, `sub`, `adc`, `mul`, `div`, `mod`
- Используются условными переходами `jeq`, `jne`, `jlt`, `jgt`
- При прерывании сохраняются/восстанавливаются аппаратно (через `reti`)

## 12. Такты выполнения (для hw)

Каждая инструкция выполняется за несколько тактов:

| Стадия | Что происходит |
|---|---|
| Fetch | Прочитать байты инструкции из памяти (1 такт за каждые 2 байта) |
| Decode | Декодировать опкод и операнды, выставить сигналы CU |
| Execute | Выполнить операцию (АЛУ, чтение/запись памяти) |
| Writeback | Записать результат в регистр |

Для `load`/`store` с кэшем:
- Попадание в кэш: +1 такт
- Промах: +10 тактов
