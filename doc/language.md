# Спецификация языка kot

Язык высокого уровня с синтаксисом, напоминающим JavaScript/Java 
Предназначен для трансляции в машинный код CISC-процессора с жесткой логикой управления (Hardwired Control), архитектурой фон Неймана и аппаратным стеком
## 1. Типы данных
В языке используется один базовый тип данных: **32-битное знаковое целое число** (Machine Word). 
Строки и символы трактуются как последовательности байт в памяти.

## 2. Структура программы
Программа на языке `kot` должна иметь следующую структуру:

```kot
interrupt {
    // Код обработчика прерываний (всегда первым!)
}

// Основная программа
let переменные...
основной код...
```
**Правило:** Блок `interrupt { ... }` **всегда** должен быть первым в файле. Это необходимо для корректного размещения кода в памяти (обработчик прерываний должен находиться по адресу `0x0000`).

## 3. Переменные и присваивание
Переменные объявляются через ключевое слово `let`. Все переменные размещаются в области глобальных переменных (`0x3000 – 0x3FFF`) с выравниванием 4 байта.

```kot
let x = 10;          // Объявление и инициализация
x = x + 5;           // Переприсваивание
let sum = a + b;     // Сложение
let diff = a - b;    // Вычитание
let prod = a * b;    // Умножение
let quot = a / b;    // Целочисленное деление
let rem = a % b;     // Остаток от деления
let shifted = a << 2; // Сдвиг влево (эквивалент умножения на 4)
let masked = a & 0xFF; // Побитовое И (маска для выделения младшего байта)
let combined = a | b;  // Побитовое ИЛИ
```

## 4. Зарезервированные переменные
Переменная `count` является **зарезервированной** и всегда размещается по адресу `0x3000`. Она используется для подсчёта количества символов, полученных через прерывания.

**Правило:** Пользователь **не должен** объявлять переменную `count` через `let`. Она автоматически доступна в блоке `interrupt` и в основной программе.

while (условие) {

## 6. Ограничения на выражения
Для упрощения трансляции и корректной работы с регистрами, выражения должны следовать следующим правилам:
- В одном выражении может быть **не более одного оператора** (`+`, `-`, `*`, `/`, `%`).
- Если требуется более сложная математика, необходимо разбивать её на несколько `let`:
  ```kot
  // Вместо: let x = a * b + c * d
  let temp1 = a * b
  let temp2 = c * d
  let x = temp1 + temp2
  ```

## 7. Работа с вводом-выводом

```kot
// Работа с байтами (для строк и символов)
let val = read_byte(0x80);       // Прочитать 1 байт из адреса 0x80
print_byte(val, 0x84);           // Записать 1 байт val в адрес 0x84

// Работа со словами (32-бит)
let word = read_word(0x90);      // Прочитать 32-битное слово
print_word(word, 0x94);          // Записать 32-битное слово
```

### Правила для адресов в вызовах функций
Аргументы функций `print_byte`, `print_word`, `read_byte`, `read_word` могут быть:
- Числовыми константами: `0x84`, `0x4000`
- Именами переменных: `count`, `addr`
- Простыми выражениями вида `база + индекс`: `0x4000 + count`

**Правило:** Сложные выражения внутри скобок (например, `0x4000 + count + 1`) **не поддерживаются**. Необходимо предварительно вычислить адрес в переменную:
```kot
let addr = 0x4000 + count + 1
print_byte(s, addr)


## 8. Прерывания
Для работы с прерываниями в языке предусмотрена специальная конструкция `interrupt`:

```kot
interrupt {
    let s = read_byte(0x80)
    print_byte(s, 0x4000 + count)
    count = count + 1
}
```

**Правила:**
- Блок `interrupt` должен быть **один** в программе и **всегда первым**.
- Транслятор размещает код из этого блока по адресу вектора прерывания (`0x0000`).
- Остальной код программы размещается после (с адреса `0x0100`).
- При возникновении прерывания процессор автоматически переходит к выполнению этого блока.
- Блок должен завершаться командой возврата из прерывания (транслятор добавляет `reti` автоматически).
- Внутри блока `interrupt` для чтения данных из порта ввода используется специальный регистр `R_INT` (см. спецификацию ISA).
- Транслятор автоматически добавляет **пролог** и **эпилог** для сохранения и восстановления регистров `R0–R3` в зарезервированную зону памяти (`0x0088 – 0x00FF`), чтобы основная программа не теряла свой контекст.
